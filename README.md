# Análisis de Datos – Ventas de Panadería

Curso: Herramientas Básicas para el Análisis de Datos Autora: Florencia de la Fuente

Descripción del proyecto

Este proyecto tiene como objetivo analizar un conjunto de datos de ventas de una panadería para identificar patrones de comportamiento, conocer los productos más rentables y evaluar la relación entre las promociones y las unidades vendidas.

El trabajo se desarrolló a través de las etapas de exploración, limpieza, análisis y visualización de datos.

Preguntas de investigación

¿Qué productos generan mayor ganancia?

¿Las promociones influyen en la cantidad de unidades vendidas?

¿Qué días de la semana presentan mayor volumen de ventas?

Herramientas utilizadas

Python y Google Colab: exploración, limpieza y análisis de datos.

Pandas: manipulación y procesamiento del conjunto de datos.

Power BI: creación del dashboard interactivo y visualización de resultados.

GitHub: almacenamiento y organización de los archivos del proyecto.

Principales resultados

Producto más rentable: Coffee registró la mayor ganancia total, con 35.301,44.

Promociones: los registros con promociones presentaron un promedio de 5,38 unidades vendidas, frente a 4,78 sin promociones, lo que representa una diferencia aproximada del 12,6 %.

Comportamiento semanal: el sábado fue el día con mayor volumen de unidades vendidas, mientras que el lunes registró el menor.

Los resultados muestran patrones interesantes en el comportamiento de las ventas y permiten identificar oportunidades para la toma de decisiones comerciales.

Estructura del repositorio

data/raw/: archivos del conjunto de datos.

notebooks/: notebook de Google Colab con el proceso de análisis.

dashboard/: archivo del dashboard desarrollado en Power BI.
